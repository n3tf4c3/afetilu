# Afetilu

Aplicativo gratuito para familiares e cuidadores de pessoas autistas registrarem observações do dia a dia e levarem um resumo descritivo às consultas. Os dados ficam só no aparelho.

## Apoio

O Afetilu é gratuito e continua gratuito. Quem quiser apoiar o projeto pode usar o botão **Sponsor** deste repositório (GitHub Sponsors). É totalmente voluntário: o app não pede doação nem muda nada para quem apoia.
